# Proyecto final Minería de Datos: análisis de Fórmula 1 con CRISP-DM

Proyecto de la asignatura Minería de Datos (ciclo 2026B, sección D09, NRC 227395) del Centro Universitario de Ciencias Exactas e Ingenierías (CUCEI), Universidad de Guadalajara. El trabajo sigue la metodología CRISP-DM y utiliza el conjunto de datos *Formula 1 World Championship (1950–2026)* de Kaggle, aplicado al caso de la estrategia de una escudería de Fórmula 1.
